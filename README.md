# Take Away

A responsive supply chain command center with shipment visibility, delivery performance, a logistics photo, and a network map.

## Dashboard features

- Search shipments and cycle through live-status filters.
- Create shipments in the dashboard and export shipment data as CSV.
- Responsive desktop and mobile layout.

## Demo data

Shipment metrics and carrier updates are sample data. Connect a logistics API and map provider to use live operational data.

The site is a static, self-contained `index.html` file. Import this repository into Vercel with no build command and the root directory as the output.
